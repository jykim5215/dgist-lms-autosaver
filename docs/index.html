붕어빵

DGIST LMS AutoSaver

붕어빵은 DGIST LMS의 강의 자료를 자동으로 찾아 내 Google Drive에 과목·주차별로 정리해 주는 개인용 데스크톱 앱입니다. 새 자료가 올라왔는지 확인하고, 업로드 상태를 웹 대시보드에서 관리할 수 있습니다.

주요 기능

  • DGIST LMS 로그인 및 강의 자료 탐색
  • 여러 과목의 파일을 강의별·주차별로 자동 분류
  • Google OAuth 기반 Google Drive 연동 업로드
  • Gemini API를 이용한 자료 요약
  • 웹 대시보드에서 설정·동기화·검증 실행
  • 사용자별 작업공간 분리 모드

설치와 실행

소스 코드와 설치 방법은 GitHub 저장소에서 확인할 수 있습니다. 앱은 사용자의 PC에서 직접 실행되며, 별도의 중앙 서버로 자료를 보내지 않습니다.

첫 실행 시 pip install -r requirements.txt 후 pythonw app.py 로 실행합니다.
