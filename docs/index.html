붕어빵

붕어빵은 DGIST LMS에 올라온 강의 자료를 자동으로 찾아 이용자 본인의 Google Drive에 과목별·주차별로 정리해 주는 개인용 데스크톱 애플리케이션입니다.

이 앱이 하는 일

붕어빵은 이용자를 대신해 DGIST LMS에 로그인하여 수강 중인 과목의 강의 자료를 찾아 내려받고, 그 파일을 이용자 본인의 Google Drive에 과목·주차 폴더 구조로 업로드합니다. Google 계정 연동(OAuth)은 오직 이 업로드와 중복 확인을 위해서만 사용합니다.

주요 기능

  • DGIST LMS 로그인 및 강의 자료 탐색
  • 여러 과목의 파일을 강의별·주차별로 자동 분류
  • Google OAuth 기반 Google Drive 연동 업로드
  • Gemini API를 이용한 자료 요약 (선택)
  • 웹 대시보드에서 설정·동기화·검증 실행
  • 사용자별 작업공간 분리 모드

Google 계정으로 무엇을 하나요

붕어빵은 이용자의 Google Drive에 강의 자료를 업로드하고, 이미 올라간 파일인지 확인하기 위해서만 Google 계정에 접근합니다. 앱은 이용자의 PC에서 직접 실행되며 개발자가 운영하는 서버는 없습니다. 이용자의 파일이나 인증 정보는 개발자에게 전송되지 않습니다.

설치와 실행

소스 코드와 설치 방법은 GitHub 저장소에서 확인할 수 있습니다.

첫 실행 시 pip install -r requirements.txt 후 pythonw app.py 로 실행합니다.
