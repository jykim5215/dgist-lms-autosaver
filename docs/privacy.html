개인정보처리방침

붕어빵 (DGIST LMS AutoSaver) · 최종 수정일 2026년 8월 13일

붕어빵(이하 "본 앱")은 DGIST LMS의 강의 자료를 이용자 본인의 Google Drive에 정리해 주는 개인용 데스크톱 애플리케이션입니다. 본 방침은 본 앱이 어떤 정보를 다루고, 어떻게 보관하며, 어디로 전송하는지를 설명합니다.

1. 기본 원칙

  • 본 앱은 이용자의 컴퓨터에서 직접 실행됩니다. 개발자가 운영하는 중앙 서버는 없습니다.
  • 이용자의 자료와 인증 정보는 이용자의 기기에만 저장되며, 개발자에게 전송되거나 수집되지 않습니다.
  • 본 앱은 어떤 정보도 판매하거나 광고 목적으로 사용하지 않습니다.

2. 처리하는 정보

구분내용저장 위치
DGIST LMS 로그인 정보강의 자료 탐색을 위한 학교 계정 아이디·비밀번호이용자 기기의 로컬 설정 파일
Google 계정 인증 토큰Google Drive 업로드를 위한 OAuth 액세스·리프레시 토큰이용자 기기의 token.json
강의 자료 파일LMS에서 내려받은 강의 파일 및 그 목록·메타데이터이용자 기기 및 이용자 본인의 Google Drive
Gemini API 키자료 요약 기능을 쓸 때 이용자가 직접 입력한 키이용자 기기의 로컬 설정 파일

3. Google 사용자 데이터의 이용

본 앱은 Google OAuth를 통해 이용자의 Google Drive에 접근합니다. 접근 권한은 다음 목적으로만 사용합니다.

  • LMS에서 받은 강의 자료를 이용자 본인의 Drive에 업로드
  • 과목·주차별 폴더 생성 및 중복 업로드 방지를 위한 파일 목록 확인

본 앱은 Google 사용자 데이터를 개발자의 서버로 전송하지 않으며, 제3자에게 제공하거나 판매하지 않습니다. 또한 광고, 프로파일링, 인공지능 모델 학습에 사용하지 않습니다.

본 앱의 Google 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 준수합니다.

4. 제3자 서비스

  • Google Drive API — 이용자 본인의 Drive에 파일을 업로드하기 위해 사용합니다.
  • Google Gemini API — 이용자가 요약 기능을 켠 경우에 한해, 해당 자료의 내용이 요약 생성을 위해 Google에 전송됩니다. 선택 기능이며 끌 수 있습니다.
  • DGIST LMS — 강의 자료를 가져오기 위해 이용자를 대신해 로그인합니다.

5. 보관과 삭제

모든 데이터는 이용자의 기기에 보관되며, 보관 기간은 이용자가 결정합니다. 다음 방법으로 언제든 삭제할 수 있습니다.

  • 앱 폴더의 token.json, config.json, downloads/, users/ 삭제
  • Google 계정 권한 관리에서 본 앱의 액세스 권한 해제
  • 앱 자체를 삭제하면 관련 로컬 데이터도 함께 제거됩니다

6. 보안

인증 정보는 이용자 기기에만 저장되며 개발자에게 전송되지 않습니다. 다만 개인 기기의 물리적·계정 보안은 이용자의 책임입니다. 공용 컴퓨터에서는 사용 후 반드시 로그아웃하고 로컬 설정 파일을 삭제하시기 바랍니다.

7. 아동의 개인정보

본 앱은 DGIST 재학생을 대상으로 하며, 만 14세 미만 아동을 대상으로 하지 않습니다.
